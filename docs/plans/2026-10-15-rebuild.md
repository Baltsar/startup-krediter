# Startup-krediter Rebuild Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Turn the one-door Nordic eligibility checker into a comprehensive skill for startup funding and credits, money and compute, Nordic and global, with program facts stored as data instead of code.

**Architecture:** `data/programs.json` holds one record per program with eligibility rules expressed as data. `scripts/match.py` is a small generic evaluator that reads the data, applies the rules to a profile, and prints ranked doors as JSON. `references/*.md` hold the prose per domain that the model reads for judgment. `SKILL.md` is the workflow that ties intake, matching, live status checks and the answer format together, with the reasons behind each rule.

**Tech Stack:** Python 3.12+ standard library only at runtime (the README promises "Python 3. No packages."). Tests are pytest, run through `uv run --with pytest pytest tests/` so nothing is added to the repo. JSON Schema draft 2020-12 as documentation, enforced by a hand-written stdlib validator.

**Spec:** The task brief from the analysis session, condensed in "Global Constraints" and "Spec coverage" below. The analysis found: facts accurate, shape wrong (aphoristic SKILL.md, glyph-only output, 1186 lines of duplicated Python with hardcoded dates, no tests, empty credits branch, live Vinnova call unreachable from the documented path).

## Review Focus

Five inputs the spec implies but a careless implementation would break. Each has a test in the owning task.

1. **Profile without `country`.** Must not default to Sweden. Every country rule evaluates to unknown and the first question is the country. Test in Task 3 (`test_no_country_is_unknown_not_sweden`).
2. **Numeric field delivered as a string** (`"revenue_msek": "5"`). Comparison must not raise. Treat non-numeric as unknown and add a `warnings` entry. Test in Task 3 (`test_string_number_is_unknown_with_warning`).
3. **EU programs for EEA and associated countries.** EIC Accelerator and Eurostars accept Norway and Iceland. Relevance for `country: "EU"` uses an EU-plus-associated set, not EU27. Test in Task 3 (`test_eu_program_relevant_for_norway`).
4. **`last_verified` malformed or in the future.** The validator rejects it. Test in Task 1 (`test_rejects_future_last_verified`).
5. **Stack aliases and case.** `"Anthropic"`, `"claude"`, `"AWS"` must all match. Normalize to lowercase and map aliases (`claude` to `anthropic`, `chatgpt` to `openai`, `google` to `gcp`). Test in Task 3 (`test_stack_aliases_normalized`).

```json
{
  "id": "vinnova-innovativa-startups",
  "name": "Vinnova Innovativa Startups",
  "country": "SE",
  "kind": "grant",
  "need": ["money"],
  "who": "Swedish limited company, at most 10 years old, at most 10 employees, at most 10 MSEK revenue or balance sheet, no dividend last year.",
  "what": "Grant for a nine-month innovation project that tests the market. Covers up to 100 percent of project cost.",
  "amount": {"max": 500000, "currency": "SEK", "text": "Up to 500 000 SEK"},
  "eligibility": [
    {"field": "country", "op": "eq", "value": "SE", "label": "Swedish company", "question": "Is the company registered in Sweden?"},
    {"field": "legal_form", "op": "eq", "value": "company", "label": "limited company", "question": "Is it an aktiebolag?"},
    {"field": "age_years", "op": "lte", "value": 10, "label": "at most 10 years", "question": "How old is the company?"},
    {"field": "employees", "op": "lte", "value": 10, "label": "at most 10 employees", "question": "How many employees?"},
    {"any": [
      {"field": "revenue_msek", "op": "lte", "value": 10, "label": "revenue at most 10 MSEK", "question": "Revenue last fiscal year, in MSEK?"},
      {"field": "balance_msek", "op": "lte", "value": 10, "label": "balance sheet at most 10 MSEK", "question": "Balance sheet total, in MSEK?"}
    ], "label": "revenue or balance sheet at most 10 MSEK"},
    {"field": "profit_distributed", "op": "eq", "value": false, "label": "no dividend last year", "question": "Did the company pay a dividend last year?"}
  ],
  "apply_url": "https://www.vinnova.se/e/innovativa-startups/innovativa-startups-2026",
  "status_url": "https://www.vinnova.se/e/innovativa-startups/innovativa-startups-2026",
  "live": {"source": "vinnova", "call_id": "2016-04714"},
  "next_step": "Create an account at etjanster.vinnova.se, open the call, fill the application. The account owner clicks submit.",
  "reference": "references/nordic-grants.md#vinnova-innovativa-startups",
  "last_verified": "2026-10-15",
  "notes": "Scores 0 to 5. Very high scores are granted, high and equal scores are drawn by lot, low scores are rejected. Opened 12 Oct 2026, closes 12 Jan 2027 14:00, decision 23 Mar 2027."
}
```

Field semantics:

- `country`: ISO-2, or `EU` (open to EU, EEA and Horizon-associated countries), or `global`.
- `kind`: `grant`, `loan`, `compute`, `cloud_credit`, `ai_api_credit`, `accelerator`, `perks`.
- `need`: which asks this door answers. Filtering uses the intersection with `profile.need`.
- `eligibility[]`: a rule `{field, op, value, label, question}` or a group `{any: [rule, ...], label}`.
  - `op`: `eq`, `neq`, `in`, `not_in`, `lte`, `gte`, `lt`, `gt`, `contains` (list field contains value).
  - Rule result: `met` when the field is known and the comparison holds, `failed` when known and it does not, `unknown` when absent.
  - Group result: `met` if any member is met; `failed` if every member is known and failed; otherwise `unknown`.
- `live`: optional. `{"source": "vinnova", "call_id": "..."}` is the only source in this plan. With `--live`, match.py attaches `{"round": title, "closes": iso, "apply_url": url}` or `{"error": message}`.
- `status_url`: the page the model fetches before quoting a date, an amount, or whether a round is open.
- `last_verified`: ISO date the page was read. The matcher flags records older than 90 days as `stale`.

## match.py contract

```
python3 scripts/match.py [--all] [--live] [--programs data/programs.json] [--today YYYY-MM-DD] < profile.json
```

Output:

```json
{
  "profile": {"country": "SE", "legal_form": "company", "age_years": 2, "employees": 4, "need": ["compute", "credits"], "stack": ["anthropic", "aws"]},
  "warnings": ["revenue_msek is not a number, treated as unknown"],
  "stale": ["some-program-id"],
  "doors": [
    {
      "id": "eurohpc-playground",
      "name": "EuroHPC Playground",
      "kind": "compute",
      "country": "EU",
      "status": "unknown",
      "met": ["company", "2 years", "4 people"],
      "failed": [],
      "unknown": [{"label": "employment", "question": "Is the project lead employed until at least three months after the allocation ends?"}],
      "glyph": "◐  EuroHPC Playground\n●  company\n○  employment\n○  VAT number\n?  Is the project lead employed until at least three months after the allocation ends?\n→  Up to 5 000 GPU hours, 1 to 3 months, one system, first come first served.",
      "what": "...",
      "amount": {"text": "..."},
      "next_step": "...",
      "apply_url": "...",
      "status_url": "...",
      "reference": "references/compute.md#eurohpc-playground",
      "last_verified": "2026-10-15",
      "stale": false,
      "live": null
    }
  ]
}
```

Relevance: a program is relevant when `need` intersects `profile.need` (or `profile.need` is absent) and its country matches: equal ISO-2, or `EU` with the profile country in the EU-plus-associated set, or `global`. A profile without a country keeps every program and marks every country rule unknown.

Status: `blocked` if any rule failed, `eligible` if every rule is met, otherwise `unknown`.

Sort: eligible first, then unknown by fewest unknowns, then blocked. Blocked doors are omitted unless `--all`. Ties keep `programs.json` order, so the data file controls the default order inside a tier.

Glyph header: `●` eligible, `◐` unknown, `×` blocked. Body: `●` met labels, `×` failed labels, `○` unknown labels, `?` the first unknown question, `→` the `amount.text` plus the live `closes` date when present.
